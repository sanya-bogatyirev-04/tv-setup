# LG webOS

Статус: исследование. Готовой версии и подтверждённого набора возможностей пока нет.

Это отдельное платформенное направление. Android APK не является установочным пакетом webOS. Для ТВ-приложения нужны собственная реализация, упаковка и процесс распространения.

Замена системного главного экрана, запуск локального торрент-сервера и доступность выбранного медиаплеера требуют отдельной проверки. Полное совпадение с Android-версией не обещается.

[Официальное руководство LG](https://webostv.developer.lge.com/develop/getting-started/build-your-first-web-app)
