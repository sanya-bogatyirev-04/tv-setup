# Samsung Tizen

Статус: исследование. Готовой версии и подтверждённого набора возможностей пока нет.

Это отдельное платформенное направление с правилами упаковки, подписания и распространения Samsung. Для обычных Samsung TV web-приложения используются пакеты WGT; Android APK здесь не устанавливаются.

Сценарий запуска установочного файла с флешки не переносится с Android автоматически: в официальной документации Samsung обычная установка WGT с USB не поддерживается. Замена Home, локальный сервер и доступность медиаплеера требуют отдельной оценки.

[Официальные ограничения установки](https://developer.samsung.com/smarttv/develop/faq/application-installation.html)
