# Архитектура и структура

## Граница репозитория

Публичный репозиторий содержит описание продукта, концепт интерфейса, требования и статусы платформ. Готовые приложения, рабочие исходники, закрытая конфигурация, ключи подписи и инфраструктура выдачи доступа не включены.

## Планируемые части Android-решения

| Часть | Ответственность |
| --- | --- |
| Мастер | Проверка совместимости, согласия, установка пакетов и отчёт о результате |
| Каталог поставки | Проверенные версии, архитектуры, подписи и условия распространения пакетов |
| Необязательная оболочка | Главный экран, папка приложений, управление пультом и оформление |
| Адаптеры настройки | Проверенные способы подключения и настройки сторонних приложений |
| Локальная медиасвязка | Подготовка сервера и проверка взаимодействия клиента и плеера |
| Сохранение конфигурации | Доступный снимок исходного состояния, настройки интерфейса и возврат |

Это архитектурный план. Наличие готовых реализаций перечисленных частей не заявляется.

## Разделение платформ

Общие сценарии и визуальные принципы описываются в `docs/`. Платформенные возможности и ограничения размещаются отдельно:

- `platforms/android/` — установка APK, Android Home и системные подтверждения.
- `platforms/lg-webos/` — отдельная реализация и распространение по правилам webOS.
- `platforms/samsung-tizen/` — отдельная реализация и распространение по правилам Tizen.

Один универсальный установочный файл для трёх ОС не планируется. Наличие Android-версии не означает доступности тех же приложений, замены системного Home или локального сервера на остальных платформах.

## Выдача доступа

Витрина доступна для ознакомления. Условия получения рабочего продукта согласовываются отдельно. Конкретные технологии активации, модель оплаты и гарантии поддержки ещё не объявлены.
