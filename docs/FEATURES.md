# Концепция продукта

Первый целевой сценарий — мастер настройки для совместимого Android-устройства с управлением пультом.

1. Пользователь устанавливает один пакет мастера.
2. Мастер проверяет устройство и наличие Lampa, TorrServe MatriX и Vimu.
3. Недостающие медиаприложения устанавливаются с необходимыми системными подтверждениями. Возможность включения конкретных сторонних пакетов в поставку определяется их условиями.
4. Перенастройка уже установленного приложения согласовывается отдельно.
5. Новый главный экран предлагается добровольно. При отказе используется прежняя оболочка, а установка медиаприложений продолжается.
6. При согласии показываются три медиаплитки и папка остальных запускаемых приложений. Данные существующих программ сохраняются.
7. Пользователь может изменить оформление и порядок плиток.

Автоматизация настроек сторонних приложений, локальный сервер и замена Home зависят от ОС, прошивки и доступных интерфейсов. Поддержка конкретной модели должна быть подтверждена. Работа на LG webOS и Samsung Tizen исследуется отдельно.
