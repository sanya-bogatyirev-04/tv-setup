# Запрос доступа

Рабочий продукт предоставляется по отдельной договорённости. Этот репозиторий содержит только публичную демонстрацию и описание.

Для обращения используйте шаблон **«Запрос доступа»** в Issues этого репозитория. Укажите:

- Целевую платформу и версию ОС.
- Нужные функции.
- Личный, демонстрационный или коммерческий сценарий.

Не публикуйте контакты, серийные номера, IP/MAC-адреса, учётные данные, ключи и журналы устройства. Публичная заявка не означает автоматическую выдачу доступа. Частные условия обсуждаются отдельно по согласованному каналу.

Доступность версии, совместимость, объём поставки, разрешённое использование и условия обновлений согласовываются до выдачи продукта. Наличие активатора, сервера лицензий или конкретной модели оплаты сейчас не заявляется.
